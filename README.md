# Was du wirklich zustimmst – TikTok

Interaktive Beamer-Präsentation (18 Slides) + Arbeitsblatt zum Thema **TikTok-AGB** für die Medienbildung in Klasse 7/8 (ca. 40 Minuten).

## Inhalt
- `index.html` – Single-File-Präsentation (Pfeiltasten / Wischen, `Esc` = Übersicht), läuft offline und auf dem iPad.
- `build_arbeitsblatt.py` – erzeugt Schüler- und Lösungs-Arbeitsblatt (`python-docx`).
- `Arbeitsblatt_TikTok_AGB.docx` / `…_Loesungen.docx` – fertige Arbeitsblätter.

## Vier Schwerpunkte
1. **Wem gehören deine Videos?** – Inhalte-Lizenz + KI-Training
2. **Der Algorithmus** – Datensammlung (Tipprhythmus, Standort) + „Für dich"-Feed
3. **Wohin gehen deine Daten?** – Konzern/Behörden + 530-Mio-€-Strafe (China, 2025)
4. **Geld-Fallen** – LIVE-Geschenke & Coins
